# magpie 路由组与档位配置

这套配置里所有模型都写成 magpie 路由组名（`group/<id>`），不写供应商前缀。组名不带版本号，以后换来源或升级模型，只改组成员，agent 文件、派活手册、Orca 命令都不用动。

下面命令里的 `<来源>` 换成你在 magpie 里的供应商 id（`magpie providers` 可以看到）。

## 1. 先存一份快照

```text
magpie save 改前-路由组
```

想撤回时 `magpie use 改前-路由组`。

## 2. 建五个组

```text
magpie group add glm-main models=<来源>/glm-5.3 routing=order
magpie group add glm-fast models=<来源>/glm-5.3-flash routing=order
magpie group add minimax  models=<来源>/MiniMax-M3.1-Flash routing=order
magpie group add ds-flash models=<来源>/deepseek-flash routing=order
magpie group add opus     models=<来源>/claude-opus-5-5 routing=order
```

`magpie groups` 确认五个组都在。

## 3. 让 Claude Code 的档位也指向组

每条命令都必须带模型值。`magpie claude opus` 这种不带值的写法会把 magpie 从该档位摘掉。

```text
magpie claude group/glm-main
magpie claude opus group/glm-main
magpie claude sonnet group/glm-main
magpie claude haiku group/minimax
magpie claude fable group/glm-fast
magpie claude subagent group/glm-fast
magpie claude haiku_effort medium
magpie claude subagent_effort high
```

opus 档指向 glm-main 是有意的：Opus 主会话里 `model="opus"` 会解析成主会话自己，所以 opus 档实际只在非 Opus 会话里生效。真正要用 Opus 的地方（verifier、主会话）直接写 `group/opus`。

## 4. 升级模型

例如 GLM 出了 5.5：

```text
magpie group set glm-main models=<来源>/glm-5.5
```

## 5. 核对落点

```text
magpie usage --csv --last 1h
```

看 `requested_model`、`served_model`、`effort` 三列，确认每个 agent 落在预期的模型和推理档位上。agent 文件里写 `group/glm-fast:high[1m]` 这种"组名 + 档位"的写法，实测 Claude Code 能识别，magpie 会按档位发出。
