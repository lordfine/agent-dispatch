# 工作区预热模板

项目：<项目名>；执行机：<执行机名>；共享缓存根目录：<绝对路径>。
共享目录放在工作区外，同一执行机、同一用户复用；Windows 与 Linux 分开。
每个工作区独立安装 `.venv`、`node_modules`，只共享下载缓存。
下面骨架按项目语言删选；外部命令失败必须立即退出，禁止写入密钥。

## Linux：项目的 `脚本/预热.sh`

bash 变量名只用英文。

```sh
#!/bin/sh
set -eu
CACHE_ROOT='<执行机共享缓存绝对路径>'
export UV_CACHE_DIR="$CACHE_ROOT/uv"
export npm_config_cache="$CACHE_ROOT/npm"
export PLAYWRIGHT_BROWSERS_PATH="$CACHE_ROOT/playwright"
uv sync --frozen  # Python 项目示例
npm ci           # Node 项目示例；按项目保留需要的命令
# <其他项目初始化命令；缓存不要放进工作区>
```

## Windows：项目的 `脚本/预热.ps1`

```powershell
$ErrorActionPreference = 'Stop'
$缓存根 = '<执行机共享缓存绝对路径>'
$env:UV_CACHE_DIR = Join-Path $缓存根 'uv'
$env:npm_config_cache = Join-Path $缓存根 'npm'
$env:PLAYWRIGHT_BROWSERS_PATH = Join-Path $缓存根 'playwright'
uv sync --frozen
if ($LASTEXITCODE -ne 0) { exit $LASTEXITCODE }
npm ci
if ($LASTEXITCODE -ne 0) { exit $LASTEXITCODE }
# <其他项目初始化命令；按项目保留需要的命令>
```

## Playwright 内核只预装一次

执行机准备阶段，设置同一个 `PLAYWRIGHT_BROWSERS_PATH` 后运行项目的
`uv run playwright install chromium` 或 `npx playwright install chromium`；Linux 系统依赖由执行机维护者准备。
每台执行机每个 Playwright 所需版本装一次；升级版本时补装，多个工作区共享。
运行测试的终端也必须设置此变量，setup 子进程的环境不会自动传给后续终端。

## 接入 Orca（仅说明，本票不执行）

已核对 `orca repo --help`、`orca repo set --help`：当前 CLI 无写 setup 钩子的参数。
在 Orca 仓库设置的 setup 配置中登记上述脚本，实际界面字段需主脑核对后填写。
Linux 命令：`sh 脚本/预热.sh`；Windows 命令：`pwsh -NoProfile -File 脚本/预热.ps1`。
已核对创建参数：`orca worktree create --repo "id:<仓库ID>" --name "<工作区名>" --setup run --json`。
`--setup inherit` 继承仓库策略，`--setup skip` 跳过，旧参数 `--run-hooks` 等同强制运行并切到工作区。
