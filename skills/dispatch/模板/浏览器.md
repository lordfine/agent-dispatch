# 浏览器使用规则

分工：自动回归用 Playwright（WSL 里无头跑）；agent 手动验收、截图、需要登录态的操作用 ego-browser。只是给本地页面截图，用无头 Edge 或 Chromium 就够了，不必动 ego-browser：
```text
msedge --headless=new --window-size=1280,860 --virtual-time-budget=2500 --user-data-dir=<临时目录> --screenshot=<输出.png> <file:///页面>
```

## ego-browser
先运行 `ego-browser skill`，按当前版本的指南操作。
agent 默认进专用 profile，不碰用户自己的登录态。新建任务空间时指定 profileId（具体 ID 见个人配置 `~/.claude/派活配置/本机条件.md`）：
```js
const t = await taskSpace("<任务名>", { profileId: "<专用 profile ID>" });
```
- profileId 只在新建任务空间时生效，复用已有空间时不会切换 profile；任务空间名不能重复。
- Windows 上脚本里有中文或比较复杂时，写进 UTF-8 文件，用 `ego-browser nodejs < 脚本.js` 执行。
- ego-browser 窗口最小化时截不了图（0.6.2.8 实测）。
- 不导入其他浏览器的资料，不登录账号，不读 cookie 内容。

## 登录态
- 只有用户明确授权的任务，才能进用户指定的 profile 或空间。
- 用登录态的任务串行执行，不清理 cookie、缓存或其他状态。
- 提交、发送、删除之前先问用户，等明确同意。
