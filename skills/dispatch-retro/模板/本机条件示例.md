# 本机条件示例

首次配置时照这份生成 `~/.claude/派活配置/本机条件.md`。以下数值和名称都是示例，按实际情况填；每条后面是怎么问出来或怎么查。

- 层级：`<基础|底座|进阶>`。基础只有 Claude Code 或 Codex；底座加 Orca、magpie；进阶加 WSL 或远程执行机、多模型组合。查 `orca --version`、`magpie groups`、`wsl -l -v`。
- 在用的组合：`<组合名>`，文件在 `组合/<组合名>.txt`。问用户想用哪套，从 skill 自带的示例组合复制一份按来源改。没有 magpie 就写“无”。
- 并发：worker 2 个、前台子代理 2 个、WSL 或测试机同时跑测试的 worker 1 个、全量测试 4 进程、浏览器 1 个。问用户机器能承受多少，结合实测调整；全量进程数还要受测试库连接上限约束。
- 额度：模型来源 `<来源>`，订阅或按量 `<类型>`，每分钟请求上限 `<数值>`，额度预警线 `<百分比>`，到预警线时怎么办（提醒还是降并发）。问用户套餐和偏好，用 `magpie accounts <来源>` 或服务商后台核对。
- 预算：每月 `<金额>`，怎么折算。问用户愿意承担的月预算。
- 偏好：质量和成本怎么取舍、难活默认用哪个组加哪个档、审查投入多少。问用户，给出推荐。
- 机器：CPU `<核心数>`、内存 `<容量>`，WSL `<有或无，资源>`、Docker `<有或无>`。查系统信息。
- 远程执行机：服务器名 `<名称>`、连接地址 `<地址>`、envId `<标识>`、项目 repoId 和路径 `<…>`。问用户用哪台，从 `orca` 的远程服务器和项目登记核对。
- 浏览器专用 profile：`<配置名称>`。问用户哪个配置专供 agent 使用。
- 模型使用禁忌：`<模型及限制>`。问用户哪些模型不适合哪些任务，以及是否有共享额度限制。
- 改派规则：内容审核、限流时改派给谁。按在用组合写。
