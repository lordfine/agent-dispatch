# 国产组合示例：Opus 主脑 + GLM / MiniMax / DeepSeek 干活
# 每行一条 magpie 命令；# 开头是注释。用 切换组合.py 应用。
# 先用 magpie providers 查到自己的供应商 id，把 <国产来源>、<Claude来源> 替换掉。
# 成员写法：供应商/模型[:推理档位][:fast]。写了档位就压过 agent 文件和调用方传的档位；
# 示例把档位限制在 medium 到 xhigh 之间，可按实际需要调整。GLM 和 DeepSeek 只有 low/high/max，所以落到 GLM/DeepSeek 上一律钉 high。
# impl、impl-strong 在 Codex 组合里写成 :medium+high+xhigh，由 --effort 在这三档里选；国产组合里 GLM 只有 high，所以钉 :high，组上的 levels 仍收在三档内。
magpie group add explore models=<国产来源>/MiniMax-M3.1-Flash:medium routing=order
magpie group add extract models=<国产来源>/MiniMax-M3.1-Flash:medium routing=order
magpie group add research models=<国产来源>/glm-5.3-flash:high routing=order
magpie group add review models=<国产来源>/glm-5.3-flash:high routing=order
magpie group add diagnose models=<国产来源>/glm-5.3-flash:high routing=order
magpie group add write models=<国产来源>/deepseek-flash:high routing=order
magpie group add verify models=<Claude来源>/claude-opus-5-5:high routing=order
magpie group add impl models=<国产来源>/glm-5.3-flash:high routing=order levels=medium,high,xhigh
magpie group add impl-strong models=<国产来源>/glm-5.3:high routing=order levels=medium,high,xhigh
