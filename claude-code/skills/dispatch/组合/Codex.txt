# Codex 组合示例：Opus 主脑 + Codex 三个模型干活（全部开 fast，第二顺位是国产模型兜底）
# 每行一条 magpie 命令；# 开头是注释。用 切换组合.py 应用。
# 先用 magpie providers 查到自己的供应商 id，把 <Codex来源>、<国产来源> 替换掉。
# Codex 额度用完或账号不可用时，routing=order 会自动顺延到第二个成员。
# 额度紧张时的降级办法：把 Astra 换成 Sol、Sol 换成 Terra，或把 :xhigh 改 :high、:high 改 :medium。
# stays=turn：每轮新对话都从第一顺位 Codex 重新试，避免一次断网后长会话一直留在兜底模型（在一台测试机上，2026-11-06 实测 stays=auto 时约七成请求滞留 GLM）。
magpie group add explore models=<Codex来源>/gpt-6.1-terra:medium:fast,<国产来源>/MiniMax-M3.1-Flash:medium routing=order stays=turn
magpie group add extract models=<Codex来源>/gpt-6.1-terra:medium:fast,<国产来源>/MiniMax-M3.1-Flash:medium routing=order stays=turn
magpie group add research models=<Codex来源>/gpt-6.1-sol:high:fast,<国产来源>/glm-5.3-flash:high routing=order stays=turn
magpie group add review models=<Codex来源>/gpt-6.1-sol:xhigh:fast,<国产来源>/glm-5.3-flash:high routing=order stays=turn
magpie group add diagnose models=<Codex来源>/gpt-6.1-sol:high:fast,<国产来源>/glm-5.3-flash:high routing=order stays=turn
magpie group add write models=<Codex来源>/gpt-6.1-terra:high:fast,<国产来源>/deepseek-flash:high routing=order stays=turn
magpie group add verify models=<Codex来源>/gpt-6-astra:high:fast,<国产来源>/glm-5.3:high routing=order stays=turn
magpie group add impl models=<Codex来源>/gpt-6.1-sol:medium+high+xhigh:fast,<国产来源>/glm-5.3-flash:high routing=order stays=turn levels=medium,high,xhigh
magpie group add impl-strong models=<Codex来源>/gpt-6-astra:medium+high+xhigh:fast,<国产来源>/glm-5.3:high routing=order stays=turn levels=medium,high,xhigh
